# 法语学习网页 UI 优化方向

候选来自 `search-design-system` 的桌面端与移动端索引检索。检索条件覆盖教育、语言学习、词汇、消费应用、列表/首页、浅色和中等信息密度。以下方案只借鉴通用设计原则，不复制候选品牌的商标、专有字体或未经授权的图片。

## 方案 A：游戏化成长型

**检索参考：Duolingo Web + Mobile**

- 白色主画布，绿色作为唯一主行动色；正确、进度、继续学习形成统一反馈。
- 首页突出“今日下一步”，词汇与语法练习使用大题面和明确进度条。
- 卡片和按钮采用约 12px 圆角与轻微按压层次；文案短、友好、有鼓励感。
- 移动端把四类学习入口改成底部导航，操作目标不小于 44px。
- 适合：希望提高复习率、连续学习率和低龄/大众用户参与感。
- 风险：过度游戏化会削弱 B1/B2 用户需要的专业感；不应复制 Duolingo 角色、Logo 或字体。

## 方案 B：极简专注型

**检索参考：Ollama**

- 黑、白、灰为主，法式蓝只用于当前等级和焦点状态。
- 页面像一本干净的学习手册：窄阅读栏、大留白、无渐变、无投影。
- 搜索、等级选择与操作按钮统一为胶囊形；词表使用细分割线而非卡片堆叠。
- 每个页面只保留一个最醒目的主要操作，例如“开始本轮学习”。
- 适合：成人自学、长时间阅读、B1/B2 密集词库和桌面学习。
- 风险：技能检索中它没有匹配消费应用和中等密度条件，需要额外补充学习反馈和移动端策略。

## 方案 C：词汇发现型

**检索参考：Pinterest**

- 暖白背景、显著搜索栏、等级与词性筛选胶囊，词汇以可收藏的主题卡片呈现。
- A1–B2 首页可以按旅行、饮食、工作、情绪等主题形成多列发现流。
- 桌面端使用多列词汇卡；移动端依次缩为 2 列、1 列，保留自然内容高度。
- 强调色建议改成法式海军蓝或酒红，不直接复制 Pinterest 红。
- 适合：词库浏览、主题词表、收藏和探索式学习。
- 风险：检索匹配的是内容平台/编辑式列表，并非严格教育产品；学习进度仍需独立模块承载。

## 推荐组合

建议以 **方案 B 作为整体视觉基础**，保持现有项目克制、清晰的成人学习气质；在练习页面采用 **方案 A 的进度和正反馈机制**；在新增 A1–B2 分级词库中采用 **方案 C 的搜索、筛选与发现结构**。这样能避免整站视觉过于娱乐化，同时让大量词汇数据仍然易于浏览。
